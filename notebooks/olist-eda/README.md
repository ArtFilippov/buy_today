# EDA собранного Olist

Основной результат — **[report.ipynb](report.ipynb)**: выполненное исследование
с 13 графиками, таблицами качества и рекомендациями для будущего baseline.
Все графики строятся кодом notebook из локальных входов.

## Что обнаружено

- 96 068 позиций, 35 столбцов; 84 130 заказов, 81 541 пользователь и 30 991 товар.
  Дубликатов ключа `(order_id, order_item_id)` нет.
- 97,16% пользователей имеют один наблюдаемый заказ. В трёх временных
  90-дневных holdout-окнах история есть лишь у 1,30–2,11% пользователей.
- 57,12% проданных товаров встречаются в одной позиции; top-1% товаров
  даёт 21,18% позиций. Плотность матрицы user–item — 0,003442%.
- Фильтр единственного продавца удаляет 12,82% delivered-позиций,
  неодинаково по категориям; 328 оставшихся корзин неполные.
- 2 046 строк (2,13%) имеют хотя бы один пропуск. География покупателя
  отсутствует в 7,55% позиций DF против 0,26% по всем позициям.
- Найдены 148 заказов с перевозчиком раньше покупки, 23 с доставкой раньше
  перевозчика, 4 позиции с координатами вне грубой рамки Бразилии,
  445 несовпадений штата продавца с геосправочником, 8 нулевых масс.
- Медиана цены — 69,90 BRL, p99 — 899 BRL. Стоимость доставки связана
  с расстоянием (Spearman 0,633); связь сохраняется в проверенных подгруппах.
- Медиана срока доставки — 10,15 дня; позднее обещанного дня доставлены
  6,59% заказов с известными датами. Отбор по согласованным датам почти
  не меняет медиану. Удаление строк с пропусками также мало меняет основные
  общие выводы, но не решает локальные проблемы покрытия.

**Главное для рекомендаций:** набор подходит для исследования признаков и
учебных синтетических экспериментов. Реальная персональная оценка ограничена
короткими историями и cold start. Отбор по конечному статусу и продавцам за
всю историю ретроспективен; метрики на синтетике не оценивают реальную полезность.

## Открыть и воспроизвести

Из корня репозитория:

```bash
uv sync --frozen
.venv/bin/jupyter lab notebooks/olist-eda/report.ipynb
```

Для пересборки вспомогательных данных, PNG и выполненного notebook:

```bash
.venv/bin/python datasets/olist-eda/collect_reference.py
MPLBACKEND=Agg .venv/bin/python notebooks/olist-eda/explore.py
.venv/bin/python notebooks/olist-eda/build_report.py
```

Исходные CSV должны лежать в `dataset/`; подготовленная таблица создаётся
корневым `prepare_data.ipynb`. После изменения данных или графиков перед
сборкой отчёта нужна повторная содержательная и визуальная проверка.
