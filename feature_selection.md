# Отбор признаков

Для первой версии выбраны все 35 столбцов из `dataset/olist_prepared_dataset.csv`; решение зафиксировано в [README](README.md#утверждённый-набор-столбцов). В колонке «Для чего может понадобиться» указаны возможные применения. Колонка «Комментарий» оставлена для заполнения.

| Признак | Краткое описание | Для чего может понадобиться | Комментарий |
|---|---|---|---|
| `order_id` | Идентификатор заказа | Объединение позиций в заказ; вместе с `order_item_id` образует ключ исходной строки | |
| `order_item_id` | Номер позиции внутри заказа | Различение позиций и повторных единиц товара; проверка дубликатов | |
| `customer_id` | Идентификатор покупателя в рамках конкретного заказа | Связывание заказа с записью покупателя в исходных таблицах | |
| `customer_unique_id` | Сквозной идентификатор реального покупателя | Объединение разных заказов одного человека; исследование реальных историй покупок | |
| `product_id` | Идентификатор товара | Построение матрицы user–item; подсчёт популярности; идентификация товаров в рекомендациях | |
| `price` | Цена товара в позиции заказа, в бразильских реалах | Сравнение покупок по ценовому уровню; моделирование предпочтений по стоимости | |
| `freight_value` | Стоимость доставки, отнесённая к позиции заказа | Учёт расходов на доставку и итоговой стоимости покупки | |
| `order_status` | Статус заказа; в подготовленном наборе везде `delivered` | Контроль состава выборки; в текущем наборе не различает покупки | |
| `order_purchase_timestamp` | Дата и время оформления заказа | Временная сортировка и разбиение данных; исследование сезонности; сохранение исходного времени Olist | |
| `order_approved_at` | Дата и время подтверждения оплаты | Анализ задержки между оформлением и подтверждением; становится известна после оформления | |
| `order_delivered_carrier_date` | Фактическая дата передачи заказа перевозчику | Анализ скорости обработки заказа продавцом; описывает этап после покупки | |
| `order_delivered_customer_date` | Фактическая дата доставки покупателю | Расчёт фактического срока доставки и опоздания; описывает результат покупки | |
| `order_estimated_delivery_date` | Обещанная дата доставки на момент покупки | Расчёт ожидаемого срока доставки; сравнение обещанного и фактического сроков | |
| `customer_zip_code_prefix` | Первые пять цифр почтового индекса покупателя | Присоединение геоданных; выделение территорий доставки; индекс является кодом, а не числовой мерой расстояния | |
| `customer_city` | Город покупателя из таблицы покупателей | Учёт локальных предпочтений и географическая группировка покупок | |
| `customer_state` | Штат покупателя из таблицы покупателей | Учёт региональных различий с небольшим числом категорий | |
| `customer_geolocation_lat` | Медианная широта для почтового префикса покупателя | Описание географии спроса; расчёт приблизительного расстояния до продавца | |
| `customer_geolocation_lng` | Медианная долгота для почтового префикса покупателя | Вместе с широтой — географические расстояния и пространственная группировка | |
| `customer_geolocation_city` | Город из наиболее частой пары «город–штат» для почтового префикса покупателя | Проверка согласованности адресных данных; дополнительный источник географии | |
| `customer_geolocation_state` | Штат из наиболее частой пары «город–штат» для почтового префикса покупателя | Проверка соответствия `customer_state`; дополнительный источник региона | |
| `seller_zip_code_prefix` | Первые пять цифр почтового индекса продавца | Присоединение геоданных; определение территории отправления | |
| `seller_city` | Город продавца из таблицы продавцов | Учёт места отправления и региональной доступности товаров | |
| `seller_state` | Штат продавца из таблицы продавцов | Группировка товаров по региону отправления; признак совпадения штатов продавца и покупателя | |
| `seller_geolocation_lat` | Медианная широта для почтового префикса продавца | Описание расположения продавца; расчёт приблизительного расстояния до покупателя | |
| `seller_geolocation_lng` | Медианная долгота для почтового префикса продавца | Вместе с широтой — географические расстояния и пространственная группировка | |
| `seller_geolocation_city` | Город из наиболее частой пары «город–штат» для почтового префикса продавца | Проверка согласованности адреса продавца; дополнительный источник географии | |
| `seller_geolocation_state` | Штат из наиболее частой пары «город–штат» для почтового префикса продавца | Проверка соответствия `seller_state`; дополнительный источник региона | |
| `product_category_name` | Категория товара; при наличии перевода используется английское название | Описание тематической близости товаров; моделирование предпочтений по категориям | |
| `product_name_lenght` | Длина названия товара в символах | Характеристика оформления карточки товара | |
| `product_description_lenght` | Длина описания товара в символах | Характеристика подробности карточки товара | |
| `product_photos_qty` | Количество фотографий товара | Характеристика полноты визуального представления товара | |
| `product_weight_g` | Вес товара в граммах | Сравнение товаров по физическим характеристикам; описание факторов стоимости доставки | |
| `product_length_cm` | Длина товара в сантиметрах | Сравнение габаритов; расчёт объёма и пропорций | |
| `product_height_cm` | Высота товара в сантиметрах | Сравнение габаритов; расчёт объёма и пропорций | |
| `product_width_cm` | Ширина товара в сантиметрах | Сравнение габаритов; расчёт объёма и пропорций | |

Названия `product_name_lenght` и `product_description_lenght` сохранены с исходным написанием из Olist.
