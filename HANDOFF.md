## Контекст решений, который важно сохранить

- Сравниваются готовые начальные датасеты: один `fit` на train и оценка test **той же папки**, без k-fold, validation, генерации или накопления историй. Принятый пользователем синтаксис — повторяемые строки `--model "svd --n-components 16"`.
- Пользователь явно выбрал рейтинг **по максимуму NDCG по датасетам**. Не заменять его средним или средним местом. Все правила выбора runs и совместимости описаны в README.
- Публикация всего вызова обеспечивается общим маркером `.completed/<invocation-id>.json`. Он записывается атомарным переименованием только после подготовки и переноса всех runs. Reader сначала получает список маркеров и выбирает runs из него; staging и аварийные неопубликованные каталоги не участвуют в выборе. При переносе результатов нужен весь root, включая `.completed/`.
- Резервирование новых каталогов не допускает перезаписи run; последовательные коллизии timestamp и перевод часов назад обрабатываются увеличением времени на микросекунду. Это не распределённый планировщик параллельных запусков.
- `--no-save-model` действительно исключает сериализацию. Обучение и оценка выполняются в памяти; сохранённые модели используют общий формат и подходят для существующих `inference` и `evaluate-ranking`.
- `fit_seconds` и `evaluation_seconds` измеряют соответственно только вызовы `fit` и `evaluate_ranker`, без чтения/записи файлов. Пути модели в метриках указывают на конечный run, а не staging.
- Отчёту нужны только сохранённые метаданные и результаты. SHA-256 входов сравниваются между моделями без открытия исходных датасетов. Название датасета сохраняет basename переданной папки, в том числе для directory symlink.
- Matplotlib импортируется при построении графиков, а не при обычном импорте `prak.ranking`. Новых зависимостей нет.

## Проверки и review

Итоговые команды после всех исправлений:

```bash
uv run pytest tests/ranking
# 323 passed in 113.00s

uv run pytest tests/test_cli.py tests/generation/test_generation_cli.py tests/test_container_cli.py
# 163 passed in 249.78s

git diff --check
# без ошибок
```

- Всего **486 прошедших тестов**, включая **97 новых**: 41 runner, 44 report, 12 CLI. Полный pytest всего репозитория в этой сессии не запускался.
- Для второго набора нужен timeout больше 120 секунд: первый запуск был прерван лимитом, повторный с лимитом 600 секунд прошёл полностью.
- Review по спецификации нашёл реальный численный крайний случай: существующий оценщик при идеальной выдаче из 32 релевантных товаров возвращает NDCG `1.0000000000000002`. Строгая верхняя граница отчёта отвергала такой успешно опубликованный run. Регрессионный тест сначала воспроизвёл ошибку; проверка отчёта теперь допускает отклонение `1e-12`, сохраняя исходные метрики и score без округления или изменения оценщика.
- Review структуры привёл к общему writer сохранённой модели и отложенным импортам Matplotlib. Проверки повторены после этих изменений.
- Тепловые карты и сравнительный график визуально просмотрены на синтетических результатах: шкалы 0–1, кириллица, длинные имена и отметки равных победителей читаются. Временные изображения находились в `/tmp/opencode/`; они не являются артефактами проекта.
